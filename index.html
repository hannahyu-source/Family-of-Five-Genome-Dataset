Family of Five – Genome Dataset

Zeeshan-ul-hassan Usmani's Genome Phenotype SNPs Raw Data

01 데이터 분석
  • Zeeshan-ul-hassan Usmani가 공개한 "My Complete Genome"이라는 개인 유전체 데이터
  • 23andMe 유전자 검사 결과: rsid(SNP 식별자), 염색체 번호, 염기 위치(position), 유전형(genotype) 형태의 표 구조
  • 후속·연계 데이터 "Family of Five – Genome Dataset"
02 분석 질문
  • 부모의 조상 기원(ancestry) 마커는 서로 얼마나 일치하는가?
  • 특정 형질을 결정하는 유전자가 어떻게 유전되는가?
  • 서구 데이터셋과의 비교했을 때 GWAS와의 일치도와 예측정확도는?
  • 혈연관계가 확인된 부모와 자녀로 구성된 2세대 가족 유전체 데이터의 연구적 가치와 차별성은?
03 데이터 사전
  • 데이터의 열 이름, 의미, 단위, 데이터형, 결측, 이상치
  • SNP(유전자 마커) 총 개수
  • 염색체(chromosome)별 분포
  • 유전자형(genotype) 구성
  • 결측치/노콜(no-call) 비율
  • 성염색체(X, Y)와 미토콘드리아(MT) 데이터 유무
04 전처리 로그
  • 인코딩/헤더 정리
  • 결측/노콜
  • position, chromosome 타입 변환
  • 이형접합 여부
  • 5개 파일을 rsid 기준으로 병합(merge)
05 시각화
  • 염색체별 SNP 개수 막대그래프 (구성원별 비교)
  • 이형접합 비율 비교 막대그래프 (아빠/엄마/자녀1/2/3)
  • 가족 구성원 간 유전자형 일치율 히트맵 (rsid 교집합 기준으로 누가 누구와 더 비슷한지)
  • 특정 염색체의 position별 genotype 분포 산점도
  • 형제자매 3명 간 유사도를 비교하는 클러스터링/덴드로그램
06 인사이트
  • 멘델 유전 법칙 검증 - 부모 기원 추정
  • 형제자매 간 유전적 유사도
  • 이형접합도(heterozygosity) 비교
